# Shell-CPP-Implementation ```>_```

This is my implementation of an Operating System shell.

# Current supporting commands

| NAME | Description | Example |
|:-------:|:-------:|:-------:|
| **echo** | Outputs string to stdout| echo "hello world" |
| **exit** | Kills the current terminal process | exit |
| **type** | Determines whether the command is valid   | type echo|
| **pwd** | Prints the current working directory | pwd |
| **cd** | Moves current directory to different context | cd /example-directory |



# Additional Features

This terminal is capable of executing executable and able to process for shell redirection direction. Additionally, complex quotations management, and escape characters are also featured.
